多端同步方式

支持 4 端自动合并

免费额度极高，最适合 Windows + 安卓四端无缝同步。在四台设备上填入相同配置与同步口令即可。

首次使用：在 Supabase SQL Editor 执行建表语句 
create table if not exists vocab_sync (
  sync_id text primary key,
  payload jsonb not null,
  updated_at timestamptz default now()
);
alter table vocab_sync enable row level security;
create policy "allow_all_by_sync_id" on vocab_sync for all using (true) with check (true);

通过 Microsoft Graph API 将同步文件 lexisync_data.json 直接存入你的个人 OneDrive（不经过任何第三方服务器）。

提示：在 Microsoft Graph Explorer 登录个人微软账号并勾选 Files.ReadWrite 即可快速获取令牌；若长期免登录刷新，建议部署到静态托管并配置 Azure AD SPA Client ID。

兼容坚果云、Nextcloud、Alist 等支持 HTTPS WebDAV 的网盘。

注意：部分网盘（如坚果云）在浏览器端直接请求可能受跨域限制，如遇同步失败建议优先使用 Supabase 云同步或配置轻量 Cloudflare Worker 代理。

如何在两台 Windows 和两台安卓设备上像 App 一样使用？

将本单文件 HTML 重命名为 index.html 上传到免费的 Cloudflare Pages / GitHub Pages / Vercel 获得专属 HTTPS 网址。在 Windows 的 Chrome/Edge 地址栏点击「安装应用」，在安卓 Chrome/Edge 菜单点击「添加到主屏幕」，即可在四台设备上获得全屏独立 App 体验，并通过上方云同步保持进度一致。
